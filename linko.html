Linko: Bookmark & Link Manager

Bookmark Manager Jetpack Compose Quick Save 100% On-Device & Private

An elegant, privacy-first mobile bookmark manager and secret text vault built with Android Jetpack Compose and local Room SQLite storage. Save URLs and code snippets instantly via system text selection, Quick Save share sheet, or Quick Settings Tile—with optional biometric PIN protection for private folders.

VIEW ON GitHub App Privacy Policy Support & Feedback

Core Bookmark & Organization Features

Smart Link & Text Classification

Automatic URL detection and domain parsing instantly format incoming text or web links into clean bookmarks with auto-generated titles.

System Quick Save Sheet & QS Tile

Save links from any app without interrupting your flow using Android's system text selection menu, standard Share Sheet, or Quick Settings status bar tile.

Custom Folders & Cover Media

Organize links into custom category folders complete with custom icons, color palettes, and optional local cover images for quick visual discovery.

Folder Biometric & PIN Lock

Protect sensitive folders and personal notes using fingerprint biometrics, facial recognition, or custom PIN codes with seamless Android BiometricPrompt.

Instant Instant Search & Filtering

Search through saved titles, web addresses, and text contents instantly across all folders or pinpoint specific categories in real time.

100% Local Room SQLite Vault

Your saved bookmarks and private notes never touch the cloud. Stored strictly inside an encrypted local SQLite database on your device.
